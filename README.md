# Bodegón Delicia - Website Template

Sitio web profesional diseñado para restaurantes, bodegones y negocios gastronómicos. Enfocado en la conversión y la experiencia del usuario.

## Demo
Puedes ver la versión en vivo aquí: [bodegon-delicia-web.vercel.app]

## Características
- **Diseño Responsive:** Optimizado para móviles, tablets y escritorio.
- **Secciones:** Inicio, Menú Digital, Galería de Platos y Contacto.
- **Performance:** Carga ultra rápida con código limpio (HTML5/CSS3).
- **SEO Friendly:** Estructura optimizada para motores de búsqueda.

## Tecnologías
- HTML5
- CSS3 (Custom Properties y Flexbox)
- JavaScript para interacciones básicas
